# The Colors from Deep Space

A mod for the game [The Message from Deep Space](https://store.steampowered.com/app/4080030/The_Message_from_Deep_Space/) that allows you to change your color scheme.

**Please complete up until Act 3 before reading further or installing the mod.**

## Features

All features of this mod are customised via the config file. Load the game with the mod enabled to generate the config file, then edit it to your liking.

### Color Palette

You can customise the color palette used by the monitor UI and the various buttons/dials/gadgets around your desk. All vanilla and custom color palettes are detailed in the [Palettes](README.md#Palettes) section below.

### Randomization

If `VanillaColorPalette` is set to `Random`, there are a few extra settings you can configure.

`RandomizationType` controls when to randomize the color scheme:
- `OnLoad` randomizes whenever you load the game
- `OnPuzzleComplete` bases the color palette on the current transmission
- `OnWeekComplete` bases the color palette on the current week
- `OnDelay` randomizes based on a number of seconds, set by `RandomizationDelay`. **WARNING:** Please do not set this to something too small if you are sensitive to flashing lights
- `OnKeyPress` randomizes every time you press a key (yes, seriously). **WARNING:** Please do not use this option if you are sensitive to flashing lights

`RandomizationBlocklist` is a comma-separated list of color schemes to ignore when randomizing.
